# 单调分块注意力的概率与音频范围
合成声学键K、值V及解码查询Q均为实数，选择能量e=Q*Ks^T+b_select，块内能量u=Q*Kc^T/sqrt(d)。Ks和Kc为两套输入键，各自回传。p=sigmoid(e)，边界路径按解码词顺序非递减，每个词从上词边界开始逐帧以概率p选择，否则继续读；起始边界为frame0。边界概率alpha是所有合法路径的质量，尚未选择的概率保留为wait，不自动加在已收最后一帧。真句末force_end=true时把剩余质量交最后有效帧；无有效帧没有上下文。
边界j的块窗口为[max(0,j-chunk_width+1),j]，在其有效且已收到位置按u做softmax，边界平均上下文为sum_j alpha_j*window_context_j。只对已选择质量返回上下文和wait，不能擅自除以1-wait伪装完整上下文。人工时窗记录约束该词边界闭区间[lo,hi]，多条同时生效，路径在时窗内因子为1、在时窗外因子为outside_factor，各条记录相乘；0在窗外表示硬排除，1表示不降权。训练为负log合法约束路径总质量加调用者上下文损失，两个分母/上游余量显式给出；无合法路径为冲突，尚未收到hi前可能为等待。完整覆盖且有合法路径的句子才进入句权分母。
在线档位给选择阈值tau及最大可前视帧L：从最后正式边界起扫描，在已确认且窗口完整的位置选择第一个p>=tau的边界，L限制相对当前采集末端的允许距离；无合格边界返回等待。临时查询可使用未确认帧，但不能提交。提交要求词序号连续、边界不小于上一正式边界且窗口都已确认。撤回只允许未提交词，撤回临时词不能移动正式起点。人工修改已提交区域的记录为新解释版本，既有字幕记录不可覆盖。
数值atol1e-7/rtol1e-5，差分梯度rtol3e-4。CPU最多4096声学帧、128词、维16、chunk_width<=64；长期活动工作区4MiB；可随机重读已确认K/V/Q文件，不得存所有路径，重放按请求限制最多64遍声学块。`events.json`给到达/确认/撤回/词时窗修订的操作输入，不预设输出结论。
